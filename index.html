Hi, I'm Ogbonna Praise-Jah Francis.

I'm a Full Stack and Mobile Developer with over three years of experience shipping mobile, web and enterprise software. At Marklite, I build scalable, user-focused mobile applications that people rely on every day, from the first wireframe to the production release.

My work spans the whole stack: Flutter and Dart on mobile, Node.js, Java and Spring Boot on the backend, and React on the web, all grounded in solid database design across SQL Server, MySQL and Oracle. I deploy to Azure using App Services, Function Apps and the surrounding infrastructure, with CI/CD pipelines that keep every release smooth and repeatable.
